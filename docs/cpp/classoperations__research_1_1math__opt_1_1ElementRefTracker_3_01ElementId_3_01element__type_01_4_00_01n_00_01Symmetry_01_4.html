Detailed Description

template<ElementType element_type, int n, typename Symmetry>
class operations_research::math_opt::ElementRefTracker< ElementId< element_type >, n, Symmetry >

A tracker for values that reference elements.

This is used to delete attributes when the elements they reference are deleted.
